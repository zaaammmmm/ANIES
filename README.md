## 📖 Deskripsi Proyek

**ANIES** adalah singkatan yang merujuk pada "Anime List Terlengkap." Proyek ini adalah sebuah aplikasi web front-end yang dirancang untuk menyediakan daftar, informasi detail, dan fitur pencarian komprehensif untuk berbagai judul anime.

Aplikasi ini bertujuan untuk memberikan pengalaman pengguna yang cepat dan responsif, memanfaatkan teknologi modern untuk menyajikan data secara efisien.

## 🛠️ Tumpukan Teknologi (Tech Stack)

Proyek ini dibangun menggunakan kombinasi teknologi front-end modern:

* **Framework/Library:** JavaScript/TypeScript 
* **Build Tool:** [Vite](https://vitejs.dev/) 
* **Styling:** [Tailwind CSS](https://tailwindcss.com/) )
* **Data Source:** Jikan API**
* **Deployment:** Netlify 

## ✨ Fitur Utama

Berikut adalah beberapa fungsionalitas inti yang disediakan oleh aplikasi ANIES:

1.  **Daftar Anime Komprehensif:** Menyajikan daftar anime yang dikategorikan atau diurutkan berdasarkan popularitas, rating, atau waktu tayang.
2.  **Pencarian Instan (Live Search):** Memungkinkan pengguna mencari judul anime secara cepat dan *real-time*.
3.  **Halaman Detail Anime:** Menampilkan sinopsis, *rating*, studio, genre, dan informasi teknis lainnya untuk setiap judul anime.
4.  **Filter dan Sortir:** Menyediakan opsi untuk memfilter daftar berdasarkan genre, status (ongoing/complete), dan tahun rilis.
5.  **Desain Responsif:** Tampilan yang dioptimalkan untuk berbagai ukuran layar (desktop, tablet, dan *mobile*) berkat penggunaan Tailwind CSS.

## 🚀 Instalasi dan Menjalankan Proyek

Ikuti langkah-langkah di bawah ini untuk mengatur dan menjalankan proyek ANIES di lingkungan pengembangan lokal Anda.

### Prasyarat

Pastikan Anda telah menginstal [Node.js](https://nodejs.org/) (disarankan versi LTS) dan Git.

### Langkah-langkah

1.  **Kloning Repositori:**
    ```bash
    git clone [https://github.com/zaaammmmm/ANIES.git](https://github.com/zaaammmmm/ANIES.git)
    cd ANIES
    ```

2.  **Instalasi Dependensi:**
    Gunakan `npm` untuk menginstal semua paket yang diperlukan (terdaftar di `package.json`).
    ```bash
    npm install
    ```

3.  **Menjalankan Mode Pengembangan (Development):**
    Jalankan perintah berikut untuk memulai server pengembangan Vite. Aplikasi akan terbuka di *browser* Anda (biasanya di `http://localhost:5173`).
    ```bash
    npm run dev
    ```

4.  **Membangun untuk Produksi (Production):**
    Untuk membuat versi siap produksi, jalankan:
    ```bash
    npm run build
    ```
    Hasil build akan tersedia di folder `dist/`.
